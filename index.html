Data Warehouse Schema


-- STAR SCHEMA DESIGN
-- Fact Tables (Business Events)
fact_transactions (transaction_id, customer_id, product_id, amount, date)
fact_support_tickets (ticket_id, customer_id, category, satisfaction_score)

-- Dimension Tables (Business Entities)  
dim_customers (customer_id, name, email, location, loyalty_tier)
dim_products (product_id, name, category, price, supplier)
dim_date (date_key, year, quarter, month, day_name)

-- SAMPLE ANALYTICS QUERY
SELECT 
    c.customer_id,
    c.first_name || ' ' || c.last_name as customer_name,
    COUNT(t.transaction_id) as order_count,
    SUM(t.total_amount) as total_spent
FROM dim_customers c
JOIN fact_transactions t ON c.customer_id = t.customer_id
GROUP BY c.customer_id, customer_name
ORDER BY total_spent DESC
LIMIT 5;

Technical Architecture Decisions


# ARCHITECTURE CHOICES
1. SQLite over PostgreSQL: Chosen for demo portability
   - Same SQL syntax, easily migratable to production DB
   - Zero configuration, file-based operation

2. Pandas for ETL: Industry standard for data manipulation
   - Handles large datasets efficiently

3. Star Schema Design: Optimal for analytics queries
   - Fast aggregation performance
   - Business-friendly data model

   - Separate extraction, transformation, loading phases
   - Pluggable data quality framework

Architecture Overview

Multi-Modal Input System:

  • Hand Tracking: MediaPipe Hands for 21-point hand landmarks
  • Eye Tracking: WebGazer.js for real-time gaze prediction
  • Voice Commands: Web Speech API for speech recognition
  • 3D Rendering: Three.js for interactive 3D environment

Core Implementation

Hand Pose Detection

// Initialize MediaPipe Hands
import * as handpose from '@mediapipe/hands';

const hands = new handpose.Hands({
  locateFile: (file) => {
    return `https://cdn.jsdelivr.net/npm/@mediapipe/hands@0.4/${file}`;
  }
});
hands.setOptions({
  maxNumHands: 2,
  modelComplexity: 1,
  minDetectionConfidence: 0.7,
  minTrackingConfidence: 0.5
});
hands.onResults(onResults);

async function onResults(results) {
  if (results.multiHandLandmarks && results.multiHandLandmarks.length > 0) {
    const landmarks = results.multiHandLandmarks[0];
    // 21-point hand landmarks
    const thumbTip = landmarks[4];
    const indexTip = landmarks[8];
    const distance = calcDistance(thumbTip, indexTip);
    if (distance < 0.05) triggerPinch();
  }
}

// Initialize WebGazer for eye tracking

Performance Optimisations

  • Frame Throttle: 150 ms intervals to stay ≤ 60 fps
  • Object Pool: Re-use Three.js meshes & vectors
  • Mobile Fallback: Disable eye-tracking on low-end GPUs
  • Progressive Loading: Models load sequentially to reduce TTI
